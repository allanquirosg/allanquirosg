## 📂 Proyectos

### 🏦 [BancoVentas – Banking Sales System](https://github.com/allanquirosg/BancoVentas-SQL)
`SQL Server` `Python` `C#` `Pandas` `NumPy`

Sistema de gestión de ventas bancarias diseñado desde cero, que modela **8 procesos financieros reales** con reglas de negocio automatizadas.

- Arquitectura completa en **SQL Server 2022**: 10 tablas y 4 schemas.
- Triggers, procedimientos almacenados y vistas para automatizar la evaluación de ventas en tiempo real.
- **8 procedimientos almacenados de reportería** que generan indicadores de desempeño comercial.
- Dos aplicaciones cliente (**Python** y **C#**) con validaciones en tiempo real.
- Análisis de datos con Pandas y NumPy, y documentación técnica en GitHub.
